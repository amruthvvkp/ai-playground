# Assignment for the module - AI and Digital Innovation

What we intend to do is take up a business use case of having customer reports come-in for a Cyber Security company. The reports are in the form of text and the company wants to automate the process of reading the reports and categorizing them into different categories. The company has a set of categories that they use to classify the reports. The company has a set of reports that are already classified and they want to use this data to train a model that can classify the new reports that come in.

## Steps to be followed
1. Create mock user data for testing, training and validation in CSV format.
2. Create a script to generate the mock user data.
3. Use GPT-2 to generate a mock user review.
4. Read the mock user review and classify it into a category.
5. Run the model on the mock user data. We need to locate the model in the model zoo.
6. AI should generate categories and classify the reports.
